# Command Aliases Lab

Welcome to a console mission, astronaut. Three nicknames for orders will save you typing and make deleting safer. Then you prove you can step around the safety nickname exactly once, without switching it off.

## Launching the Lab

Run this command to start the lab machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS006.git -c labs/lab-033
```

Open a terminal on it:

```bash
astrona ssh ats-006-lab-033
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-033
```

When you are done, remove the lab:

```bash
astrona destroy ats-006-lab-033
```
