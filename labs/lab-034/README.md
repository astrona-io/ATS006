# Sort, Count, Cut and Compare Text Lab

Welcome to a log-reading mission, astronaut. The crew roster and the visit log of this training ship hold the answers mission control wants, but they are in raw files.

Use the text filters on a pipe to build five small reports in `/home/candidate/report`.

## Launching the Lab

Run this command to start the virtual machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS006.git -c labs/lab-034
```

Open a terminal on it:

```bash
astrona ssh ats-006-lab-034
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-034
```

When you are done, remove the lab:

```bash
astrona destroy ats-006-lab-034
```
