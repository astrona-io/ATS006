# Shell History Recall Lab

Welcome to an audit mission, astronaut. Before the next shift takes over, the bridge's order log must keep what matters, skip what it should not record, and stamp every entry with a time. Then you dig two exact commands out of an earlier investigation session.

## Launching the Lab

Run this command to start the lab machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS006.git -c labs/lab-032
```

Open a terminal on it:

```bash
astrona ssh ats-006-lab-032
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-032
```

When you are done, remove the lab:

```bash
astrona destroy ats-006-lab-032
```
