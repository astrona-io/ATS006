# Question

Solve this question on: `terminal` (playing the role of `data-001` from the scenario)

1. Store the new archive under `/imports/import001.tar.gz`.
2. Compression should be the best possible, using gzip.
3. To make sure both archives contain the same files, write a list of their sorted contents into `/imports/import001.tar.bz2_list` and `/imports/import001.tar.gz_list`.
4. Do not modify or delete the original archive `import001.tar.bz2`.
