# File Operations, Links and Ownership Lab

Welcome to a cargo mission, astronaut. The cargo hold of this training ship is untidy: crates sit in the wrong compartments, a label is missing and one team does not own its crates yet.

Create, copy, move, link and remove files with the right options, and hand a compartment to the right team.

## Launching the Lab

Run this command to start the virtual machine:

```bash
astrona run --git ssh://git@github.com/astrona-io/ATS006.git -c labs/lab-024
```

Open a terminal on it:

```bash
astrona ssh ats-006-lab-024
```

When you think you have finished, send it for grading:

```bash
astrona submit -c labs/lab-024
```

When you are done, remove the lab:

```bash
astrona destroy ats-006-lab-024
```
