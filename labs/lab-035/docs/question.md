# Question

Solve this question on: `terminal`

Astronaut, the flight plan `/home/candidate/flightplan.conf` is half filled in. Edit it with `vim` or `nano`, and use the manual pages for two facts.

1. In `/home/candidate/flightplan.conf`, replace every `PLACEHOLDER` with `TBD`.
2. Change the line `checked=no` to `checked=yes`.
3. Delete the comment line at the top of the file (the line that starts with `#`).
4. Add a new last line: `launch=ready`.
5. Create `/home/candidate/answers.txt` with two lines. Find both facts in the manual pages, not from memory.
   - `passwd-file-section=<N>`: the number of the manual section that describes the **file format** of `/etc/passwd`.
   - `ls-sort-by-time=<option>`: the option of `ls` that sorts the listing by modification time, newest first, with the dash, for example `-x`.

The grader checks the exact content of both files.
